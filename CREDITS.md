## Getting the full upstream packs

Install commands as published by each upstream:

| Pack | Command |
|---|---|
| All 25 `asc` skills | `asc install-skills` or `npx skills add rorkai/app-store-connect-cli-skills` |
| All 17 `gplay` skills | `gplay install-skills` or `npx skills add tamtom/gplay-cli-skills` |
| All 24 Expo skills | `npx skills@latest add expo/skills --skill '*'` |
| Callstack's React Native skills | `npx skills@latest add callstackincubator/agent-skills --skill '*'` |
